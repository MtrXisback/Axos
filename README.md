\# Axos - Portal de Empleo Tecnológico



\## 📝 Descripción

Axos es una plataforma diseñada para conectar el talento tecnológico con las oportunidades del mercado. El sistema permite a los profesionales encontrar ofertas laborales de su interés y, a su vez, brinda a las empresas la capacidad de publicar y gestionar sus propias vacantes de manera sencilla.



\## 🚀 Tecnologías utilizadas

El proyecto ha sido desarrollado con un enfoque en robustez y rendimiento:

\- \*\*Backend:\*\* .NET 8 (ASP.NET Core)

\- \*\*Frontend:\*\* .NET 8 con Vistas en Razor y CSS personalizado

\- \*\*Base de Datos:\*\* SQL Server

\- \*\*Acceso a Datos:\*\* ADO.NET para interacciones directas y eficientes con la base de datos



\## 🛠️ Cómo ejecutar el proyecto

1\. Clona este repositorio: `git clone https://github.com/tu-usuario/Axos.git`

2\. Asegúrate de tener instalado el SDK de .NET 8 y SQL Server.

3\. Configura tu cadena de conexión en el archivo `appsettings.json`.

4\. Ejecuta los scripts SQL ubicados en la carpeta `/database` para crear la estructura.

5\. Compila y ejecuta el proyecto: `dotnet run`
